## Getting Started
### 📦 Pre-requsites
* [Python 3.11](https://www.python.org/downloads/windows/)
* [uv](https://docs.astral.sh/uv/) - `py -m pip install uv`
* git
* [Databricks CLI](https://github.com/databricks/cli)
* Just - `uv tool install rust-just`

### After `copier copy`
```
cd dbt_databricks_project
just init
```
